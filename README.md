The Inventory Management System is a Python-based tool designed to simulate a small scale inventory tracking environment. The system includes functionality to:

- Add and update product information
- Track inventory levels and simulate sales
- Generate restocking alerts
- Output summary reports to CSV


## 🔧 Features

- Modular Python codebase
- CSV based data storage and processing
- Automated unit testing for reliability
- Console based user interface
- Error handling and basic input validation

  ## 📁 Project Structure

- `main.py` - Entry point and main loop
- `inventory.py` - Core logic for managing items and stock levels
- `report.py` - Functions for report generation
- `utils.py` - Utility functions used across modules
- `tests/` - Unit tests using the `unittest` library
- `data/` - Sample CSV input/output files
